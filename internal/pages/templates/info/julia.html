A Julia set uses the same step as the Mandelbrot set, but the roles change. The number c is fixed for the whole picture, and every point of the plane is a start value z0. Repeat the step and watch whether the numbers stay near the origin:

zn+1 = zn2 +c

Once a number is farther from the origin than both 2 and |c|, it is sure to run away to infinity, so a computer can stop early:

|zn| > max⁡(2,|c|) ⇒ zn→∞

History

In 1915 the French Academy of Sciences chose the iteration of rational functions as the topic of its Grand Prix for 1918. Gaston Julia won it with a memoir of almost 200 pages; Pierre Fatou had found many of the same results independently. Julia was only 25. He had been badly wounded in the First World War, lost his nose and wore a leather strap across his face for the rest of his life. In 1945 the mathematician Szolem Mandelbrojt urged his nephew Benoit Mandelbrot to read the memoir; the young man did not take to it and came back to it only in the 1970s. Around 1980 computers finally showed what Julia and Fatou had described.

Interesting facts

  • There is a different Julia set for every number c, so there are as many of them as points in the plane.
  • The Mandelbrot set is a map of them: the Julia set is a single connected piece when c lies in the Mandelbrot set, and a cloud of infinitely many separate points, a dust, when it does not.
  • Strictly speaking, the Julia set is only the boundary. Pictures usually fill in all the points that never escape, the filled Julia set.
  • Every Julia set of this step looks the same after a half turn around the origin, because z and −z have the same square.
  • Some values have names: c = −1 gives the Basilica, c ≈ −0.123 + 0.745i the Douady rabbit, and c = i a thin branching dendrite. For c = 0 the set is just the unit circle.

How Image89 draws it

Image89 fixes c = −0.8 + 0.156i. It lies just outside the Mandelbrot set: starting from zero, the numbers escape only after 252 steps. So the true Julia set is dust, but at this depth its pieces still form a chain of thin spirals. Every pixel center becomes z0, and the step repeats until the number escapes or the limit of 256 iterations is reached. Escaped points are colored by the same smooth count as in the Mandelbrot set, from deep violet to orange and white; points that never escape are black. The view is centered at zero and is 3.2 wide and 2.4 high; for other proportions the visible area grows, so the figure is never stretched. The preset lives in the [types.julia] section of the config.
